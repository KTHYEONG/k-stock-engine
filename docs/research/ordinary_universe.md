# 날짜별 보통주 유니버스: 원본 감사와 데이터 계약

기준일: 2026-09-20. `data/bronze/stocks/security_master`의 모든 `payload.json` 2,625개를 읽고, 날짜별 원본 3개를 새 생성기로 재검증했다.

## 원본 감사

| 항목 | 확인 결과 |

| 전체 페이지 / 행 | 2,625개 / 6,345,741행 |
| 날짜가 있는 스냅샷 | 2,621개, 2016-01-04~2026-09-09 |
| 같은 날짜의 복수 페이지 / 페이지 내부 중복 티커 | 0 / 0 |

| 날짜 없는 이관·집계 파일 | 4개; 이 중 3개는 `records` 배열 없음 |
| 시점별 분류 결과 합계 | 적격 5,735,959행; 종류주 309,519행; 비주식 증권군 118,120행; SPAC 178,922행; 분류 불명 3,221행 |
| 전체 기간 적격 티커 | 2,789개 |

집계의 행 수는 **종목 수가 아니라 날짜×종목 관측 수**다. `SECT_TP_NM`은 `우량기업부` 같은 소속부 정보이며 업종이 아니다. `SPAC(소속부없음)`도 163,383행 확인됐다. 단순히 `KIND_STKCERT_TP_NM=보통주`만 검사하면 SPAC과 일부 비주식 증권군이 남는다. 날짜 없는 4개 파일은 일별 구성의 증거로 쓰지 않는다.

## Bronze → Silver 계약

| 필드·조건 | 규칙 |
| --- | --- |
| 날짜 | 원본 최상위 `as_of`/`session`을 사용하고 receipt의 요청 날짜와 일치시킨다. `retrieved_at`은 수집 이력이다. |
| 정체성 | `ISU_SRT_CD`를 티커, `ISU_CD`를 ISIN으로 보존한다. 한 날짜의 중복 티커나 충돌 ISIN은 실패한다. |
| 적격 | `KIND_STKCERT_TP_NM=보통주` ∧ `SECUGRP_NM=주권` ∧ KOSPI/KOSDAQ ∧ 비SPAC ∧ 상장일이 스냅샷일 이하. |
| 제외 사유 | `non_ordinary_share`, `non_equity_security_group`, `spac`, `unknown_*`, `not_listed_yet` 중 하나를 적는다. 모호한 행은 매수 후보에 넣지 않는다. |
| 시간 | `session`은 구성 관측일, `available_at`은 보수적으로 당일 15:30 KST. 백테스트는 이 시각 이후의 결정을 위해 사용한다. |
| 계보 | Silver 각 행에 `source_hash`, `source_security_id`, `policy_version`을 보존한다. 원본 bytes의 SHA256과 Bronze receipt를 확인한다. |
| 저장 | 날짜별 Parquet 파티션과 원본 해시·행 수·적격 수·Parquet 해시를 포함한 불변 manifest. 데이터셋 ID는 정책 버전과 날짜별 원본 해시로 결정한다. |
| 완전성 | 요청한 거래일 중 마스터가 없거나 한 날짜에 서로 다른 두 원본이 있으면 생성 실패. 현재 상장 종목 목록으로 과거 날짜를 대체하지 않는다. |

구현은 [`ordinary_universe.py`](../../src/data/ordinary_universe.py)의 `materialize_ordinary_universe_from_bronze`가 날짜별 receipt를 선택해 한 페이지씩 Parquet에 쓰는 방식이다. 기존 정규화의 `share_class`도 동일 분류기를 사용하도록 조정했다. 전체 기간 Silver 실제 생성과 가격·DART·수급 조인 검증은 별도 단계다. 기존 Silver/Gold는 아직 새 데이터셋으로 교체되지 않았다.
