# 국내주식 전략·백테스트 설계

상태: **연구 설계**. 원본 데이터 준비 현황은 [data_readiness.md](data_readiness.md)에 분리했다. 수익성은 아직 검증되지 않았다.

## 1. 투자 범위와 가설

| 결정 | 연구 계약 |
| --- | --- |
| 시장 | KOSPI·KOSDAQ의 일반 기업 보통주만. KRX 원본의 `KIND_STKCERT_TP_NM=보통주`와 `SECUGRP_NM=주권`을 모두 확인한다. 우선주·종류주권·SPAC·리츠·예탁증권·ETF·ETN 등은 제외한다. 분류 불명은 매수하지 않는다. |
| 투자 기간 | 주로 수주~수개월 보유하는 스윙·중기 투자. 일봉으로 재현할 수 없는 장중 예측·즉시 손절·호가 전략은 연구 대상에서 제외한다. |
| 첫 가설 | 유동성 있는 보통주의 6~12개월 중기 추세가 거래비용 이후에도 지속되는지 검증한다. 최근 1개월 제외, 절대 추세 필터는 소수의 사전 등록된 비교군으로만 시험한다. |
| 재무 보강 | DART 재무를 시점별로 검증한 뒤 부채·현금흐름·이익 건전성이 추세 전략의 큰 손실을 줄이는지 별도 비교한다. 정정 공시는 발표 전 시점으로 소급하지 않는다. |
| 수급 보강 | 전체 시장 백필과 단위·공급처 일치가 확인되기 전 필수 입력으로 사용하지 않는다. 커버된 종목만의 성과를 전체 시장 전략의 성과로 해석하지 않는다. |

비교군은 **A. 동일 투자 가능 집합의 단순 포트폴리오 → B. 가격 추세 → C. 가격 추세+공개 재무 → D. 수급 보강** 순서다. C와 D는 신호 효과와 데이터가 있는 종목만 남는 효과를 분리하기 위해 공통 표본에서도 평가한다. 복잡한 예측 모형은 이 비교군이 충분히 검증된 뒤 검토한다.

## 2. 종목 선정과 포트폴리오

1. 각 의사결정일의 과거 종목 마스터로 일반 기업 보통주 집합을 재구성한다. 이후 상장폐지된 종목도 당시에는 후보에 포함한다.
2. 그 시점까지의 가격·거래대금·공시만 사용한다. 신규 상장으로 이력이 부족하거나 거래량 0·거래정지·가격 이상·기업행위 미해결인 종목은 신규 매수하지 않는다.
3. 유동성은 과거 20거래일 평균 거래대금과 주문 크기의 비율로 판단한다. 절대 거래대금 문턱은 목표 계좌 규모와 원하는 청산 일수에서 역산한다.
4. 월 1회 리밸런싱을 기본 비교군으로 두고 주 1회를 회전율·실행 가능성 시험에 사용한다. 작은 순위 변동으로 불필요한 매매가 일어나지 않도록 보유/신규 진입 규칙을 사전 등록한다.
5. 동일가중을 첫 사이징 기준으로 삼는다. 변동성 역수 가중이나 시장 노출 조절은 별도 가설로 검증하며, 결과를 보고 임의로 섞지 않는다.

연구용 초기 범위는 20~30종목, 단일 종목 4~5% 이하, 무차입, 주문당 과거 20일 평균 거래대금의 0.1~0.5% 이하이다. 이는 채택 수치가 아니라 계좌 규모와 체결 스트레스에 따라 검증할 범위다. 한도는 버전 있는 설정으로 보관한다. 업종 데이터가 검증되기 전에는 업종 분산을 주장하지 않으며 실거래 승격 전에 업종 집중도를 반드시 검증한다. 한도 때문에 배분하지 못한 금액은 현금으로 남긴다.

## 3. 신호 시점과 백테스트 원장

| 단계 | 필수 규칙 |
| --- | --- |
| 데이터 사용 | `T`일 장 종료 후 당시 사용 가능했던 가격·공시로 신호를 계산한다. 공시일만 확인되는 재무자료는 다음 거래일부터 사용 가능하도록 보수적으로 둔다. 미래 자료를 바꿔도 이전 결정이 바뀌면 안 된다. |
| 주문 | 가장 빠른 주문은 `T+1`이다. 일봉의 시가를 확정 체결가로 보지 않는다. 다음 날 시가에 불리한 비용을 더한 경우, 하루 지연, 부분·미체결을 각각 평가한다. |
| 거래 불가 | 무거래·정지·가격제한·가격 이상 시 가상 체결을 금지한다. 장중 가격 경로가 없으므로 당일 저가에서 손절했다고 기록하지 않는다. |
| 현금·수량 | 원장에 실제 비조정 체결가·수량, 수수료·매도세금, 배당, 분할·합병·상장폐지 대가를 기록한다. 매일 현금+보유가치=순자산을 대조한다. |
| 연구 수익률 | 기업행위가 확인된 종목만 그 시점까지 알려진 사건으로 조정한다. 미해결 사건을 마지막 가격의 매도로 대체하지 않는다. |
| 비용 | 기간별 세금과 실제 증권사 계약 수수료를 사용한다. 스프레드·가격충격·참여율은 기본/악화 시나리오로 나누고 주문 미체결을 성과에 반영한다. |

KRX는 기업행위에 따라 기준가격을 조정하고 가격제한·매매정지를 적용한다. 따라서 전일 종가 대비 급변과 일봉 OHLC만으로 수익률이나 체결 가능성을 확정하지 않는다([KRX 기준가격](https://global.krx.co.kr/contents/GLB/06/0602/0602010201/GLB0602010201T6.jsp), [KRX 매매정지](https://global.krx.co.kr/contents/GLB/06/0602/0602010103/GLB0602010103T2.jsp)).

## 4. 평가 설계

| 질문 | 평가 방법 |
| --- | --- |
| 비용 후 성장하는가 | 순 연복리 성장률·평균 로그 성장률을 계산하고 동일 집합의 동일가중·시가총액가중 포트폴리오 및 현금과 비교한다. 기준 포트폴리오에도 같은 배당·기업행위·비용·주문 지연을 적용한다. |
| 손실을 감당할 수 있는가 | 최대 낙폭, 최악의 1년·3년, 회복 기간, 월별 손실 꼬리, 거래정지 중 평가 손실을 본다. 목표 허용 낙폭은 성과 확인 전에 계좌 규모와 함께 정한다. |
| 구현 가능한가 | 회전율, 비용 차감액, 실제 주문 크기/과거 거래대금, 부분·미체결률, 청산 소요일을 본다. 시가 전량 체결은 낙관적 상한으로만 표시한다. |
| 우연한 결과인가 | 2017년 이후 가능한 기간을 시간순 개발/평가 창으로 나누고 각 창의 규칙을 시작 전에 고정한다. 연도·시장·종목군별 기여, 인접 설정, 비용 증가·주문 지연 스트레스를 공개한다. 반복 시험 수와 실패한 가설도 기록한다. |
| 실거래로 올릴 수 있는가 | 데이터·원장 무결성을 먼저 통과해야 한다. 이후 실시간 그림자 운용과 모의주문에서 신호·주문·잔고가 일치해야 한다. 과거 연구에 사용된 기간을 독립 검증 기간으로 부르지 않는다. |

성과가 좋아 보이더라도 주식 종류, 공시 시점, 기업행위, 상장폐지 대가 또는 비용이 미해결이면 백테스트를 **인증하지 않는다**. 기존 Champion의 점수와 문턱값은 새 전략에 자동 적용하지 않는다.

## 5. 준비 순서

1. [data_readiness.md](data_readiness.md)의 일반 기업 보통주 분류·업종 근거·수급 백필·기업행위/상장폐지·비용 게이트를 해결한다.
2. 원본 해시와 시점별 사건을 고정한 재현 가능한 데이터 스냅샷을 만든다. 파생 특성 테이블은 캐시일 뿐 판단의 원천이 아니다.
3. 기준 포트폴리오의 원장과 미체결 모델을 검증한 다음 A→B→C→D를 순서대로 비교한다.
4. 채택 전 목표 계좌 규모, 허용 낙폭, 최소 순초과성장과 주문 한도를 사전 등록한다.
